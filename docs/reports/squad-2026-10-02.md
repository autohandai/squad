# Autohand Squad — work report, 1–2 October 2026

This report covers the requests in this conversation. “Implemented” means code exists; installed UI, native behavior, provider execution, telemetry ingestion, and published releases are separate checks.

## Interface and navigation

- Profile header: traffic-light clearance keeps the Squad logo in place. DM name/photo opens a compact member preview with role, live status, details, and View profile.
- Inbox and Work: one Needs you destination with Needs you, In progress, and All work filters. Unresolved decisions and blockers stay visible after marking updates read.
- macOS quick chat: small anchored frameless popover, About menu label, person icon for members without photos, one connection state, draft preservation and dismissal. The latest revision replaces the dropdown with a horizontally scrolling avatar carousel and refines the message field.
- Dock: Needs you count on the macOS app icon; zero and sign-out clear it, compact windows cannot overwrite it.

## Agents and work

- DMs show reported task checklists and preserve unfinished states on interruption. Completion is not inferred from a stopped spinner.
- /goal persists an app-owned objective across Autohand Code, Codex, and Claude Code, with pause/resume/cancel, bounded continuation and completion evidence. /break declines new work and handoffs until /break off.
- Project observation checks assigned folders while idle, suggests concrete improvements in the member's DM, and pauses for human work, breaks, or sign-out. Read-only sampling, deduplication, cooldown and daily review limits are implemented; it does not autonomously apply a suggestion.
- The installed pinned Autohand Code CLI rejects hosted background model review before receiving source evidence. Those members continue with local TODO/FIXME investigation leads, explicitly labeled with file and line evidence. Codex and Claude adapters support the model-review path; fixture coverage does not prove every live provider.
- Computer Use is a bundled capability rather than a skill: per-member observe/control grants, native consent, a managed MCP proxy, screenshots, action annotations, revocation and durable evidence. The macOS capability requires macOS 13 or later. Its component is a pinned prerelease; Squad itself has not been published as a new release.
- Squad Computer Use has its own bundle identity and icon, independent of the existing Autohand Computer Use app. Fresh macOS Accessibility and Screen Recording consent is required. Shared identity ambiguity was observed during diagnosis; it was not proven to cause the temporary native screenshot-tool failure.
- The local Squad package includes Autohand Code CLI 0.9.7 and Computer Use 0.28.2. Build-time downloads are pinned and verified; agents do not download a helper during a task.

## Account, updates and native integration

- Account login has Squad branding and no bottom-bar gap. Device authorization identifies Squad across desktop, shared API and web verification screen.
- Updates use the Squad repository and verified installer downloads. A contextual available-update banner appears above the account. Manual checks remain in native menus, About and Settings.
- About and related information windows show version, source/build details, installed executable checksum, policies, changelog and licenses.
- PostHog tracks selected account, member and feature events without prompts, paths, DOM recording or session replay, respecting privacy signals.
- Native macOS notification permission and delivery are wired, with conversation targets.

## Verification and remaining work

The final installed-build receipt and check reports accompany this file. Real provider goal continuation, live provider Computer Use execution, cross-platform permission adapters, published release installation, dashboard indexing of telemetry, and notification click-through are not established by mocked or focused checks. macOS Focus settings can suppress visible banners even when Notification Center accepts delivery.

- **Implemented and locally installed:** the interface, agent controls, account/update integration, telemetry hooks, observer and bundled macOS Computer Use listed above. The local build retains version 0.1.5 and an explicitly dirty source identity; it is not a newly published version.
- **Requires human setup:** enable Accessibility and Screen Recording for Squad Computer Use through the member's Permissions page. Both were disabled at the final readiness check, and no app-control action was attempted without them.
- **Still to verify live:** a complete provider-driven capture/control/evidence task, real goal continuation on each harness, notification click-through, a fresh Squad sign-in credential delivery roundtrip, and telemetry dashboard totals.
- **Native proof gaps:** Dock badge visual count/zero-clearing and the tray's shortened About label have code/fixture coverage but were not read successfully through native automation. The application-menu upgrade entry and installed quick-chat/permissions UI were read successfully.
- **Still to ship:** Developer ID signing/notarization and a new downloadable Squad release; Linux/Windows runtime and permission proof. macOS packaging has been built and installed locally, while the other package compositions have fixture coverage.
- **Known upstream limit:** hosted Autohand background model review is unavailable in the pinned CLI. Local factual checks remain available; broader model review needs an upstream supported isolated review path.
- **Design-only:** none of the requested features is represented solely by a design document. The ADRs explain implemented decisions; the live and release work above remains unfinished.
